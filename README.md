## ✨ Features
- **Real Portrait Integration**: Incorporates MD Saifur Rahman's real portrait photograph with responsive cropping and dark/light styling.
- **Light & Dark Theme Toggle**: Complete theme system with automatic OS preference detection and `localStorage` persistence.
- **Hero Section**: Highlights availability, core tech pills (React, TypeScript, Tailwind, Vite, Git), and direct CTA navigation with single-click resume download.
- **About Me**: Covers programming journey, analytical mathematics foundation, types of work enjoyed, and personal interests/hobbies outside coding.
- **Skills Matrix**: Categorized technical skills (Frontend, Tools & Workflow) with tabbed filters.
- **Featured Projects**: 3-column project showcase grid with preview screenshots, tech tags, details route, and direct GitHub / Live Demo links.
- **Dynamic Project Details (`/projects/:id`)**: Comprehensive architectural breakdowns, technical challenges, and roadmap.
- **Printable ATS Resume (`/resume`)**: Full, ATS-friendly printable resume with Print/Save as PDF functionality.
- **Truthful Milestones & Education**: Real academic history (National University, Satkhira Govt. College, Nalta High School) and practical engineering achievements without fabricated employment.
- **Centralized Data File**: Easy configuration via `frontend/src/data/personalInfo.js`.

## 🚀 Tech Stack
- **Frontend**: React 19, JavaScript (ES6+), React Router v7
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: React Icons
- **Bundler**: Vite 8
- **Linter**: Oxlint

## 🛠️ Local Development

### Option 1: From the Workspace Root
```bash
# Run local development server
npm run dev

# Run production build
npm run build

# Run Oxlint linter
npm run lint
```

### Option 2: From the `frontend` Directory
```bash
cd frontend
npm run dev
```
